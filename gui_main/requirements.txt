# Corelance React Application - Requirements

## System Requirements
Node.js >= 14.0.0
npm >= 6.0.0

## Core Dependencies
react@18.2.0
react-dom@18.2.0
styled-components@6.1.0
framer-motion@10.16.0
react-scripts@5.0.1

## Installation Commands
npm install

## Start Command
npm start




## Additional Notes
- HTTPS required for microphone access (localhost works for development)
- Port 3000 will be used by default
- Internet connection required for Google Fonts
